# Contributing to RupeeTrack

First off, thanks for taking the time to contribute!

## How Can I Contribute?

### Reporting Bugs

- Use the Bug Report template to report bugs.
- Ensure the bug was not already reported by searching on GitHub under Issues.
- Provide a clear description and steps to reproduce.

### Suggesting Enhancements

- Use the Feature Request template.
- Provide clear justification for the feature and how it fits into the "Quiet Security" philosophy.

### Pull Requests

1. Fork the repo and create your branch from `main`.
2. If you've added code that should be tested, add tests.
3. Ensure the test suite passes.
4. Make sure your code lints.
5. Issue that pull request!

## Code Style

- We use Prettier for code formatting.
- Follow the existing Tailwind monochromatic UI philosophy (do not introduce bright colors or standard red/green finance indicators unless explicitly part of the design system).
